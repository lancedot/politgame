# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次增强（华尔街荒诞感）

- 新增 **虚假分析师评级侧栏**：高盛 / 美林 / 摩根大通会按季度与关键选择动态调整口径。
- 新增 **季度名言弹窗**：每季度开始随机出现一句安然风格名言，强化黑色幽默氛围。
- 保留并强化 **季度随机事件反馈**：选择后会先显示结果，再进入结算。
- 保留 **季度化跑马灯**：新闻会根据季度与玩家选项变化。
- 新增 **第四季度大审判复盘**：结算时额外显示“个人资产 + 入狱年限”并给出讽刺评价。

## 三种结局

- 结局A：历史线（崩盘与追责）
- 结局B：完美犯罪（套现离场）
- 结局C：行业精英（甩锅后再就业）
