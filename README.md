# politgame - CFO Roguelike MVP

本版本重点修复了可玩性问题：数值平衡、年度KPI考核、可决策随机事件、行业化开局。

## 本轮完成

1. **上市更可达成的数值平衡**
   - IPO目标调整为：收入、净利率、经营现金流、现金、市场份额、合规。
   - 降本路径强化（组织瘦身 + 运营提效），规模达标后能走利润率改善。

2. **年度绩效考核 & 中途解聘**
   - 在 Q4/Q8 结算后进行年度KPI考核（代码中对应 turn=5/9）。
   - 若连续两次不达标，CFO 被董事会解聘，游戏中途结束。

3. **随机事件可决策 + 显示通过/失败**
   - 每回合先提交2项经营决策，再触发随机事件。
   - 事件提供2个应对选项，按成功率判定通过/失败，并在事件流显示结果。

4. **行业化初始状态**
   - 开局可选 SaaS / 制造业 / 消费品。
   - 不同行业有不同初始收入结构、成本率、资产结构与市场参数。
