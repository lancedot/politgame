# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次增强（真实感与“毒性”叙事）

- 新增 **季度随机事件弹窗**：季度结算前触发“灵魂拷问”类事件，玩家必须做出公关/操盘选择后才可结算。
- 新增 **债务塔视觉隐喻**：每次使用 SPE 隐藏债务，塔体升高并从绿→黄→红，高层后开始倾斜。
- 新增 **底部跑马灯 Ticker**：滚动显示“创新神话、监管传闻、市场危机”等叙事新闻。
- 分析师会议答案升级为 **按季度变化** 的具体回应文本，不再重复模板。
- 个人期权变现模型重新平衡：加入份额限制与流动性上限，避免个人收益不合理超过公司承压能力。
- 整体继续保留时间轴、调查进度、现实后果标签与结局复盘。

## 三种结局

- 结局A：历史线（崩盘与追责）
- 结局B：完美犯罪（套现离场）
- 结局C：行业精英（甩锅后再就业）
