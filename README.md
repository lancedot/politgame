# politgame

一个基于网页的叙事策略游戏原型：**Enron 数字恐怖游戏（硬核模拟 + 黑色幽默）**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次版本包含的四季度黑暗路线

1. **Q1 虚假黎明（MTM）**：通过乐观滑块将 20 年预期收益一次性记入当季。
2. **Q2 影子帝国（SPE）**：建立 Chewco 壳公司转移债务与亏损资产。
3. **Q3 疯狂收割（停电操盘）**：利用电力市场漏洞制造恐慌并套利。
4. **Q4 纸牌屋倒塌（终局）**：内幕套现、碎纸机行动、吹哨者处理。

## 关键系统

- 动态数值槽：Paper Gain / Real Cash / Risk / Private Account / Stock。
- 新增 **Charisma 与 Morality**：越卑劣越“自信”，但监管风险同步累积。
- 新增 **季度报告生成器**：每季自动吐出华丽且空洞的商业黑话。
- 结局：
  - A：成功逃往小岛
  - B：在法庭清算中崩盘
