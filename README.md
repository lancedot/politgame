# politgame - CFO Roguelike MVP

一个可直接在浏览器运行的 **CFO 肉鸽网页原型**：
玩家通过阅读三大报表（利润表 / 资产负债表 / 现金流量表）识别财务问题，并在现金、增长、合规三角压力下推进公司冲击 IPO。

## 本轮改进完成情况

1. **破产后不可继续**：已实现，触发现金流断裂或合规爆雷后 `gameOver=true`，按钮禁用。  
2. **Q12 结算后不可继续**：已实现，`MAX_TURNS=12`，Q12 结算后无论是否 IPO 都结束。  
3. **增加降本增效路径**：已新增 `组织瘦身`、`运营提效` 两个决策，可降低费用率/成本率提升利润率。  
4. **精简无效选项**：决策集合聚焦到增长/降本/风控/融资四类核心选项。  
5. **UI 更紧凑 + 右侧二级列表**：决策改为分类折叠列表（二级结构），页面整体密度提高。  
6. **加入随机事件**：每回合结算会触发 1 条事件（如政策补贴、竞品价格战、税务抽查），并显示事件流。  
7. **额外优化**：
   - IPO 改为净利率目标，更符合“达规模后提质增效”的玩法；
   - 日志和事件流分离，反馈更清晰。

## 快速运行

```bash
python3 -m http.server 4173
# 浏览器访问 http://localhost:4173
```
