# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 当前版本重点

- 游戏标题与叙事口径统一为“安然季度股东大会决议”。
- 每季度操作流程分为三段：
  1. 核心任务（MTM / SPE / 停机 / 终局套现）
  2. 审计沟通（体现与安达信的勾结路径）
  3. 分析师会议（问题会追踪你在 Q1 的初始选择）
- 指标面板新增：
  - 股价（Stock Price）
  - 市值（Market Cap）
  - 市场预期利润
  - 你本季虚假预测
  - 并在季度战情中给出两者差额对比

## 结局

- 决议结论 A：管理层离场
- 决议结论 B：责任追索
