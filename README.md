# politgame - CFO Roguelike MVP

本版本修复了关键交互问题，并补充了数值说明与可玩性机制。

## 本轮修复

1. **开局弹窗不消失**
   - 开始游戏后会强制关闭并隐藏开局弹窗（兼容不支持 `showModal/close` 的环境）。

2. **右侧折叠分组状态不一致**
   - 决策分组折叠状态现在可记忆；选择某项决策后不再自动重置到“增长”分组。

3. **左下角数值含义说明**
   - 在“市场&融资”面板中为每个指标增加解释文案，便于理解数值意义。

4. **保留上一版核心机制**
   - 行业化开局（SaaS/制造业/消费品）
   - 年度KPI考核与中途解聘
   - 事件二选一 + 成功率判定 + 通过/失败结果

## 运行

```bash
python3 -m http.server 4173
# 打开 http://localhost:4173
```
