# politgame - CFO Roguelike MVP

一个可直接在浏览器运行的 **CFO 肉鸽网页原型**：
玩家通过阅读三大报表（利润表 / 资产负债表 / 现金流量表）识别财务问题，并在现金、增长、合规三角压力下推进公司冲击 IPO。

## 本轮已完成的改进（针对反馈）

1. **IPO 标准可视化**
   - 增加「IPO 目标进度」面板，按收入、净利润、经营现金流、现金、市场份额、合规风险逐项显示是否达成。
2. **营销投入体感修复**
   - 营销不再只做静态乘数，改为影响市场需求与品牌势能，再通过市场模型传导到收入。
   - 日志新增回合收入变化（Revenue Δ）与关键结果，便于看到投入效果。
3. **行动点交互优化**
   - 每回合必须选择 2 个行动才能结算。
   - 选择后可再次点击取消（反选）。
4. **市场与融资复杂度增强**
   - 新增市场需求、市场份额、产品力、品牌势能、融资窗口、股权稀释等变量。
   - 新增融资相关决策（过桥融资、股权融资）。
5. **体验优化**
   - 决策卡增加效果预览文本。
   - 日志保留最近记录，避免信息过载。

## 快速运行

```bash
python3 -m http.server 4173
# 浏览器访问 http://localhost:4173
```

## 工程目录

```text
index.html        # 网页 UI 结构
styles.css        # 高级感视觉样式
app.js            # 前端游戏逻辑（可直接运行）
src/core/**       # TypeScript 引擎与数据结构（后续可继续工程化）
```
