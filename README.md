# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 教学导向更新（不含新手引导）

- 新增 **历史时间轴对照**：每季度对应真实安然事件与关键人物。
- 新增 **调查进度条**：SEC 关注、媒体热度、吹哨压力、审计独立性。
- 新增 **现实后果标签**：所有关键选项都提供“选择前影响预览”。
- 增强术语解释：在决策区内联展示 MTM / SPE / 旋转门简释，可点击展开完整解释。
- 强化审计腐蚀链：审计沟通不再直接增利，而是影响风险、现金与独立性，并触发后续反噬。
- 加入强制剧情触发：吹哨者泄露、SEC 深度问询、做空报告。
- 结局页新增 **复盘报告**：回顾你的关键决策，并映射到历史路径。

## 三种结局

- 结局A：历史线（崩盘与追责）
- 结局B：完美犯罪（套现离场）
- 结局C：行业精英（甩锅后再就业）
