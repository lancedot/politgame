# 安然：炼金术士的账本 (ENRON: The Alchemist's Ledger)

“利润是伟大的虚构，现金是凡人的诅咒，而法律，是我们早已对冲掉的风险。”

一个基于网页的叙事策略游戏原型：你将扮演 CFO，在 12 个季度里平衡三件事：
- 维持增长叙事
- 控制监管与舆情风险
- 在崩塌前完成个人资产撤离

## 运行方式

直接用浏览器打开 `index.html`。

## 主要体验（当前版本）

- 三场景状态机：
  - 【权力核心：CFO 办公室】
  - 【密室决策：暗箱实验室】
  - 【聚光灯下：华尔街布道】
- 启动沉浸式前言弹窗（登录终端后进入正式流程）。
- 关键术语提示（MTM / SPE / 旋转门）支持悬停与点击查看。
- 董事会压力采用“董事会绞索 (The Board's Gallow)”叙事风格展示。
- 结局分级（S/A/B/C/F），其中 B 线为“解雇通知书：由于平庸”。

## 关键机制摘要

- 季度循环：核心任务 → 审计沟通 → 分析师会议 → 发布财报。
- 现金危机：现金为负时触发融资救火分支。
- 风险系统：SEC、媒体、吹哨、审计独立性联动。
- 存档：`localStorage` key 为 `enron_save_v2`。
- 调试入口：`window.debug(patch)` 与 `window.gameApi`。
