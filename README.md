# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**（当前已扩展为 12 季度基线版）。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次增强（华尔街荒诞感）

- 新增 **虚假分析师评级侧栏**：高盛 / 美林 / 摩根大通会按季度与关键选择动态调整口径。
- 新增 **季度名言弹窗**：每季度开始随机出现一句安然风格名言，强化黑色幽默氛围。
- **季度随机事件所有选项均展示结果标签**（收益/风险/SEC/股价等），先看后果再决策。
- 新增 **流动性危机融资**：季度结算若现金为负，将触发非常规融资选择（预收合约 / SPE过桥 / 银行授信）。
- 新增 **公关与游说（Lobbying）**：每季度可执行一次，消耗大量现金按百分比压降风险，模拟“拿钱换时间”。
- 当利润披露低于市场预期时，系统会明确触发 **股价下跌**。
- 跑马灯去掉“待触发/待决策”占位词，仅展示已发生信息与市场动态。
- 新增 **第四季度大审判复盘**：结算时额外显示“个人资产 + 入狱年限”并给出讽刺评价。

## 结局分级（S / A / B / F）

- **S级：金融教父**（低风险 + 高套现）
- **A级：优雅脱身**（中低风险 + 有效套现）
- **B级：平庸之辈**（未满足更高等级）
- **F级：替罪羔羊**（高风险 / 高调查 / 股价崩盘）

## 达成 S 结局的推荐路径（稳定打法）

> 目标思路：**把个人资产堆到阈值以上，同时把风险压在 55 以下，并避免 SEC 过高。**

1. **Q1（资产价值重估）**
   - 乐观系数建议 `70%~75%`，避免 85%+ 的激进档。
   - 随机事件优先选更低风险的选项（不要拿短期股价去换大幅风险）。

2. **Q2（表外化）**
   - 选择 `400M` 保守档，减少后续 SEC 与杠杆放大风险。
   - 审计沟通优先“咨询费”而非“旋转门”，把风险压下来且不触发过深独立性惩罚。

3. **Q3（电网套利）**
   - 若触发高风险事件，优先后续在分析师会与审计环节做降温，避免连续叠高 SEC。
   - 本季度尽量不要执行期权变现，规避“内幕减持→闪崩概率”导致的额外调查抬升。

4. **Q4（终局）**
   - 若前三季度风险已较低（建议 <45），可选高套现方案冲刺资产；
   - 若风险偏高，先用保守沟通把风险压下，再选择温和套现方案。

5. **通用原则**
   - 任何季度出现 `SEC` 高位时，下一步优先降温，不要连续选择“强硬攻击型”话术。
   - “旋转门”只能使用一次，且会带来长期治理副作用，不建议在低风险冲 S 路线里使用。


## 参数建议（当前版本）

- 初始现金：`$800M`
- 风险警戒线：`100`，硬抓捕线：`120`
- 债务基础利息：`debt * 0.08`
- SPE 隐藏债务利息：Q1/Q2 低息（2%），Q3 跳到 8%，Q4 跳到 32%
- Q4 套现支持分批（小额/温和/极速）三档，低档更稳，高档更容易触发调查


## 2.0 基线改动（进行中）

- 游戏主循环已从 4 季度扩展到 **12 季度**。
- 新增 **董事会耐心（Board Patience）** 指标，并在季度推进中自然衰减。
- 新增中期季度（Q4-Q11）双路线：**日常经营** vs **事件驱动增长**。
- 连续两季仅日常经营会触发董事会额外不满惩罚。
- 若董事会耐心归零，将触发“平庸的牺牲品”路径。
