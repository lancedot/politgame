# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次增强（真实感与“毒性”叙事）

- 新增 **季度随机事件弹窗**：季度结算前触发“灵魂拷问”类事件，玩家必须做出公关/操盘选择后才可结算。
- 随机事件在选择后会显示 **结果反馈文本**，再由玩家确认进入正式结算。
- 新增 **底部跑马灯 Ticker**：按季度切换基础新闻，并叠加你当季事件/操作/会议发言对应的动态新闻。
- 分析师会议改为 **每季度三条不同的具体发言选项**（不再是抽象模板选项）。
- 个人期权变现模型维持平衡约束：份额限制 + 流动性上限，避免个人收益不合理超越公司承压能力。
- 保留时间轴、调查进度、现实后果标签与结局复盘。

## 三种结局

- 结局A：历史线（崩盘与追责）
- 结局B：完美犯罪（套现离场）
- 结局C：行业精英（甩锅后再就业）
