# politgame

一个基于网页的叙事策略游戏原型：**安然季度股东大会决议**。

## 运行方式

直接在浏览器打开 `index.html` 即可游玩。

## 本次更新重点

- 新增术语解释交互：在关键回合可点击查看 `MTM`、`SPE`、`旋转门` 的定义。
- 核心任务、审计沟通、分析师会议都加入了**选择前影响预估**（利润/现金/风险/股价）。
- 修正审计沟通逻辑：不再直接“凭空增加利润”，主要影响风险与现金（符合勾结/咨询费场景）。
- 新增季度末按钮：**个人期权变现**（按当季股价一次变现，影响私人账户与风险）。
- 指标面板继续展示股价、市值、市场预期与虚假预测，并在战情区显示差额。
- 文案增强为更讽刺的董事会/舆情口吻。

## 三种结局

- 结局A：历史线（崩盘与追责）
- 结局B：完美犯罪（套现离场）
- 结局C：行业精英（甩锅后再就业）
