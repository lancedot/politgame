# 安然：炼金术士的账本 (ENRON: The Alchemist's Ledger)

## 运行
直接打开 `index.html`。

## 阶段化开启逻辑（The Gated Progression）
- **第一阶段：平庸的枷锁（Q1-Q3）**
  - 仅开放：CFO 办公室 + 聚光灯下。
  - 经营动作：稳健增长 / 激进扩张。
  - 当股东压力达到 70% 会触发“恶魔的邀约”。
- **第二阶段：恶魔的邀约（Q4-Q8）**
  - War Room 解锁，MTM 比例滑块开放。
- **第三阶段：泥潭与绞索（Q9-Q12）**
  - 全场景可用，审计/游说/Chewco 按风险与现金条件逐步解锁。

## 回合与结算
- 每季度 AP=2。
- Office 主要动作会消耗 AP。
- `Publish Earnings` 为独立仪式按钮，可提前发布季报进入结算。

## 文案包（骚话版）
- 风险：`SEC 绞索紧度 (Noose Tightness)`
- 个人资产：`避税天堂余额 (Offshore Account)`
- 日常经营：`[平庸的日常 (Honest Grinding)]`
- 结算按钮：`[向华尔街撒谎 (Publish Earnings)]`
